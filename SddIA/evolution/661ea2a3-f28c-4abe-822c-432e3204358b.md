# tracker-stamp carga el ECST desde el store

`route-domain-event` entrega a `tracker-stamp` la ruta `.events/pending/{event_id}.json`. En modo redb ese fichero no existe y el sello no llamaba a Linear. Si el fichero falta, el handler carga el evento con `load_dispatched_event` usando el stem como `event_id`.
