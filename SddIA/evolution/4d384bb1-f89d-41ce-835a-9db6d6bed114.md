# LanceDB físico y memoria vectorial efectiva

Sustituye stubs JSON y vectores cero por persistencia LanceDB host-nativa.

- Tablas `thought_graph_collection` y `evolution` bajo `{paths.vectorStore}/lancedb/`.
- Pin `lancedb = 0.37.1` (0.38.0 no compila: `Error::Http` ausente).
- Toolchain: `protoc` (lance-encoding).
- Embeddings `sddia-local-hashing-v1` dim 384, sin red.
- Runtime `memory-evolution-ingest` usa el puerto; JSON no es fallback.
- Un Runtime Tokio por proceso (OnceLock) en cada adaptador.
