### Fallos suite lib — CORRECCIÓN (O13, 2026-11-14)

La versión original de esta sección los clasificó «no bloqueantes». **Error:** el plan O12 fijaba que cualquier fallo de suite bloqueaba el cierre; O12 incumplió su propia regla. Causas reales (cerradas en O13 Paso 1, suite 824 passed / 0 failed, log `man-43-o13-baseline-exec-process-lib.log`):

1. `capability_di_output_validator::ac_r8_schema_mismatch`, 2. `ac_r8_valid_payload`, 3. `ac_tracker_lifecycle_emit_v2_body` — **regresión propia de O10**: los fixtures usaban `contract_schema_rel: "x"` tras pasar a resolver el schema por `contract_schema` del binding. No era un problema del entorno. Corregidos con la ruta real y test nuevo de nombre de schema no estándar.
4. `route_domain_core::tier_dispatch::store_backed_native_capsule_does_not_use_cognitive_runtime` — **entorno del operador**: el shell exportaba `SDDIA_EXECUTE_PROCESS_BIN` con ruta relativa. Pasa con el entorno limpio; el test es ahora hermético (guarda, elimina y restaura la variable).
